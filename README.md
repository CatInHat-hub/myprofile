# 🎌 My Profile - Japanese Style Portfolio

Một trang portfolio cá nhân với phong cách thiết kế Nhật Bản hiện đại, thanh lịch và tinh tế.

## ✨ Tính năng nổi bật

- 🌸 **Phong cách Nhật Bản**: Màu sắc truyền thống, font chữ tiếng Nhật, hiệu ứng hoa anh đào rơi
- 📱 **Responsive Design**: Hiển thị hoàn hảo trên mọi thiết bị (desktop, tablet, mobile)
- 🎨 **Animation mượt mà**: Hiệu ứng scroll, hover transitions, skill bars động
- 🗂️ **Cấu trúc rõ ràng**: Tổ chức file theo chuẩn project chuyên nghiệp
- ⚡ **Tối ưu hiệu suất**: Code sạch, dễ bảo trì và mở rộng

## 📁 Cấu trúc thư mục

```
myprofile/
├── index.html              # File HTML chính
├── assets/
│   ├── css/
│   │   └── style.css       # Tất cả styles của website
│   ├── js/
│   │   └── main.js         # JavaScript cho animations và interactions
│   ├── images/
│   │   ├── projects/       # Ảnh các dự án
│   │   └── profile/        # Ảnh profile cá nhân
│   ├── icons/              # Icons custom
│   └── fonts/              # Fonts tiếng Nhật custom
└── docs/                   # Tài liệu hướng dẫn
```

## 🚀 Bắt đầu sử dụng

### 1. Clone repository
```bash
git clone <repository-url>
cd myprofile
```

### 2. Tùy chỉnh thông tin cá nhân
Mở `index.html` và thay thế các thông tin sau:
- Tên của bạn
- Chức danh/Mô tả ngắn
- Giới thiệu bản thân
- Các kỹ năng (skills)
- Dự án tiêu biểu
- Thông tin liên hệ

### 3. Thêm ảnh cá nhân
- Đặt ảnh profile vào `assets/images/profile/`
- Đặt ảnh dự án vào `assets/images/projects/`
- Cập nhật đường dẫn ảnh trong `index.html`

### 4. Chạy local
Mở file `index.html` trong trình duyệt hoặc sử dụng live server:
```bash
# Nếu có Python
python -m http.server 8000

# Hoặc dùng VS Code Live Server extension
```

## 🎨 Tùy chỉnh giao diện

### Màu sắc chủ đạo
Bạn có thể thay đổi màu sắc trong `assets/css/style.css`:
- `--primary-color`: Màu chính (vàng gold)
- `--secondary-color`: Màu phụ (xanh navy)
- `--accent-color`: Màu điểm nhấn (hồng sakura)

### Font chữ
Đã tích hợp Google Fonts:
- 'Noto Serif JP' cho tiêu đề
- 'M PLUS Rounded 1c' cho nội dung

### Hiệu ứng hoa anh đào
Có thể tắt/bật hoặc tùy chỉnh trong `assets/js/main.js`
